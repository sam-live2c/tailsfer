# Security Policy

## Supported versions

This project is under active development. Security updates are handled based on the current main branch and the latest release tags as they become available.

## Reporting a vulnerability

If you believe you have found a security vulnerability in Tailsfer, please report it privately and responsibly.

Use one of the following methods:

- open a private advisory through the GitHub Security tab for this repository, if available
- contact the maintainers through the repository's private reporting mechanism
- report the issue without exposing the details publicly in a GitHub issue or discussion

Please do not disclose the vulnerability publicly until a fix has been developed and released.

## What to include in a report

Please include:

- affected component or area of the codebase
- severity and impact assessment
- reproduction steps or proof of concept when possible
- any known mitigations
- your contact information for follow-up

## Response expectations

We will do our best to acknowledge reports promptly and work toward a coordinated fix. Security issues that affect the integrity, confidentiality, or availability of file transfer operations should be treated with urgency.

## Responsible disclosure

We appreciate responsible disclosure and will do our best to credit reporters when appropriate. Please keep reports private until a fix is ready.
